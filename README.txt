MANGEBET — Tovuti ya demo
========================

Faili:
- index.html: ukurasa mkuu, mechi/odds za mfano, na vitufe vya kwenda kwenye mechi na Spin.
- spin.html: gurudumu la Spin la demo.
- admin.html: ukurasa wa maelezo ya admin demo; si mfumo halisi wa kuingia au kuhifadhi data.
- README.txt: maelekezo haya.

JINSI YA KUPAKIA KWENYE GITHUB KWA SIMU
1. Fungua repository yako mangebet-website.
2. Pakia faili hizi kwenye mzizi (root) wa repository, si ndani ya folder jingine.
3. Ikiulizwa, badilisha faili za zamani.
4. Bonyeza Commit changes.
5. Subiri Netlify deployment ikamilike.
6. Fungua tovuti: kitufe Angalia mechi kinashuka kwenye mechi; vitufe vya Spin vinafungua spin.html.

MUHIMU
- Mechi na odds ni mifano tu; hakuna dau au malipo halisi.
- Hii si mfumo wa kamari wa pesa halisi.
- API-Football inahitaji backend/function salama kwa API key; usiweke key ndani ya HTML ya umma.
- Huduma za kubashiri kwa pesa halisi zinahitaji leseni na kufuata sheria zinazotumika.
